# Milestone 5 Blueprint: Cross-Tool Clinical Pipelines, Routing & E2E Preservation

## 1. Executive Summary

Milestone 5 unites the 4 core clinical applications (**TheraFlow EHR**, **Clinical AI Scribe v2**, **Aura Assistant**, and **HIPAA PHI Scrubber**) into a seamless, interconnected clinical workflow. This report provides the architectural blueprint for:
1. **Feature 26: Cross-Tool Clinical Pipelines**: Robust, bi-directional data pipelines (`sendToPhiScrubber`, `insertToEhr`) connecting transcript ingestion, AI differential diagnosis, clinical note generation, HIPAA statutory Safe Harbor de-identification, and EHR chart commitment.
2. **Route Registration & Access Control**: Updating `src/App.tsx`, `Header.tsx`, and `Sidebar.tsx` to register `/dashboard/aura`, `/dashboard/aura/*`, `/dashboard/phi-scrubber`, and `/dashboard/phi-scrubber/*` with `<SubscriptionGate requiredTier="starter">` and persistent quick launchers.
3. **Strict E2E Test Suite Preservation**: Ensuring **100% backward compatibility** across all 80 existing E2E tests (Tiers 1–4) certified in `TEST_READY.md`.
4. **Milestone 5 Automated Test Suite**: Comprehensive TypeScript test harness in `tests/m5-aura-scrubber.test.ts` with `"test:aura": "tsx tests/m5-aura-scrubber.test.ts"` in `package.json` covering Features 19 through 26.

### 2.2 `sendToPhiScrubber(text: string)` Implementation Design

#### Critical Constraint: Router Decoupling
In `src/App.tsx`, `ClinicalContextProvider` wraps `<Router>`:
```tsx
<AuthProvider>
  <SubscriptionProvider>
    <ClinicalContextProvider>
      <Router>
```
Furthermore, headless test harnesses (such as `tests/e2e/tier3-interactions.test.mjs` test `T3.5`) mount `ClinicalContextProvider` in JSDOM **without** a router. Calling `useNavigate()` inside `ClinicalContextProvider` causes React Router to throw:
`useNavigate() may be used only in the context of a <Router> component.`

#### Solution: Dual-Action Event Pipeline
`sendToPhiScrubber` synchronously updates context state and dispatches a standard DOM custom event:
```typescript
const [scrubberInputText, setScrubberInputText] = useState<string>('');

const sendToPhiScrubber = (text: string) => {
  setScrubberInputText(text);

  if (typeof window !== 'undefined') {
    window.dispatchEvent(
      new CustomEvent('clinical:send-to-phi-scrubber', {
        detail: { text, patient: activePatient, timestamp: new Date().toISOString() },
      })
    );
  }
};
```
In UI components (such as `TypewriterSoap.tsx` or `MultiEhrExportPanel.tsx`), when the clinician clicks "Send to PHI Scrubber":
```typescript
const handleSendToScrubber = () => {
  sendToPhiScrubber(generatedText);
  navigate('/dashboard/phi-scrubber');
};
```
This guarantees:
1. `T3.5` headless assertion `currentScrubberText === transcriptPayload` passes instantly with 0 router dependencies.
2. User interactions in the browser smoothly transition to `/dashboard/phi-scrubber` with pre-populated text.

### 2.3 `insertToEhr(note: EhrNoteInput)` Implementation Design

#### Dual Signature Handling (String vs Structured Object)
1. **String Input (Backward Compatibility for `T3.6`)**:
   - `T3.6` asserts:
     ```javascript
     const originalAssessment = getAssessment();
     const newClinicalFinding = 'DIAGNOSTIC ADDENDUM: Patient completed structured CBT panic hierarchy protocol.';
     insertNote(newClinicalFinding);
     const updatedAssessment = getAssessment();
     const appendedSuccessfully =
       updatedAssessment.includes(originalAssessment) &&
       updatedAssessment.includes(newClinicalFinding);
     ```
   - When a string is passed, it is appended to `activeEncounterNotes.assessment`:
     ```typescript
     setActiveEncounterNotes((prev) => ({
       ...prev,
       assessment: prev.assessment ? `${prev.assessment}\n\n${note}` : note,
     }));
     ```
   - It is also asynchronously recorded into TheraFlow's persistent store (`theraflow-store.ts`).

2. **Structured Note Object (SOAP / DAP Input for Feature 26)**:
   - When an object `{ subjective, objective, assessment, plan, format, data }` is passed:
     ```typescript
     setActiveEncounterNotes((prev) => ({
       ...prev,
       subjective: note.subjective ?? (note.format === 'dap' ? note.data ?? prev.subjective : prev.subjective),
       objective: note.objective ?? prev.objective,
       assessment: note.assessment ?? prev.assessment,
       plan: note.plan ?? prev.plan,
     }));
     ```

3. **Automatic TheraFlow Note Store Population**:
   To fulfill the specification: *"automatically populates TheraFlow DAP/SOAP notes in `useClinicalContext()` and active note store"*:
   - Asynchronously invoke `addNote` / `updateNote` in `@/tools/theraflow/data/theraflow-store`.
   - Wrap store synchronization in `try / catch` so test environments or isolated JSDOM runs without localStorage never fail unhandled.
   ```typescript
   // Async store persistence (non-blocking)
   try {
     const { getNotes, addNote, updateNote } = await import('@/tools/theraflow/data/theraflow-store');
     const notes = await getNotes();
     const existingDraft = notes.find((n) => n.client_id === activePatient.id && !n.is_locked);
     
     if (typeof note === 'string') {
       if (existingDraft) {
         await updateNote(existingDraft.id, {
           a_text: existingDraft.a_text ? `${existingDraft.a_text}\n\n${note}` : note,
         });
       } else {
         await addNote({
           client_id: activePatient.id,
           client_name: activePatient.name,
           client_mrn: activePatient.mrn,
           date_of_service: new Date().toISOString().split('T')[0],
           session_type: `Psychotherapy (${activePatient.cptCode})`,
           duration_minutes: 60,
           cpt_code: activePatient.cptCode,
           diagnosis_code: 'F41.1',
           d_text: 'Scribe / Aura Clinical Input',
           a_text: note,
           p_text: 'Continue active protocol',
           is_locked: false,
         });
       }
     } else {
       const dText = note.data || [note.subjective, note.objective].filter(Boolean).join('\n\n');
       if (existingDraft) {
         await updateNote(existingDraft.id, {
           d_text: dText || existingDraft.d_text,
           a_text: note.assessment || existingDraft.a_text,
           p_text: note.plan || existingDraft.p_text,
         });
       } else {
         await addNote({
           client_id: activePatient.id,
           client_name: activePatient.name,
           client_mrn: activePatient.mrn,
           date_of_service: new Date().toISOString().split('T')[0],
           session_type: `Psychotherapy (${activePatient.cptCode})`,
           duration_minutes: 60,
           cpt_code: activePatient.cptCode,
           diagnosis_code: 'F41.1',
           d_text: dText || 'Clinical documentation',
           a_text: note.assessment || '',
           p_text: note.plan || '',
           is_locked: false,
         });
       }
     }
   } catch (err) {
     console.warn('[ClinicalContext] Note store auto-population deferred:', err);
   }
   ```

### 2.4 Bi-Directional Interoperability Matrix

| Source Tool | Target Tool | Pipeline Method | Payload | Trigger UI |
|---|---|---|---|---|
| **Scribe v2** | **PHI Scrubber** | `sendToPhiScrubber(transcript)` | Raw diarized transcript or SOAP note | "Scrub PHI" button in Scribe toolbar |
| **Scribe v2** | **TheraFlow EHR** | `insertToEhr(soapNote)` | Synthesized SOAP note (`{ subjective, objective, assessment, plan }`) | "Commit to EHR" in Scribe export panel |
| **Aura Copilot** | **PHI Scrubber** | `sendToPhiScrubber(auraText)` | Typewriter SOAP or differential analysis | "Send to Scrubber" button in TypewriterSoap |
| **Aura Copilot** | **TheraFlow EHR** | `insertToEhr(soapNote)` | Generated SOAP progress note | "Insert to EHR Chart" in TypewriterSoap |
| **PHI Scrubber** | **TheraFlow EHR** | `insertToEhr(cleanText)` | De-identified Safe Harbor sanitized clinical note | "Export to EHR" button in PhiScrubberView |
| **TheraFlow EHR** | **PHI Scrubber** | `sendToPhiScrubber(chartText)` | Active client note / intake assessment | "Scrub Chart PHI" in ClientProfile & DAPNotes |

## 3. Route Registration & Access Control

### 3.1 Route Registration in `src/App.tsx`

The routing table in `src/App.tsx` must be updated to register both the index and wildcard routes for both **Aura Assistant** and **PHI Scrubber**, wrapped in `<SubscriptionGate requiredTier="starter">`:

```tsx
{/* Aura Assistant Copilot (Starter Tier) */}

  path="aura"
  element={
    <SubscriptionGate
      requiredTier="starter"
      featureName="Aura Assistant Copilot"
      headline="Aura Assistant Subscription Required"
    >
      <AuraStudio />
    </SubscriptionGate>
  }
/>
<Route
  path="aura/*"
  element={
    <SubscriptionGate
      requiredTier="starter"
      featureName="Aura Assistant Copilot"
      headline="Aura Assistant Subscription Required"

  }

{/* HIPAA PHI Scrubber (Starter Tier) */}
<Route

<Route

      headline="PHI Scrubber Subscription Required"
    >
      <PhiScrubberView />
    </SubscriptionGate>
  }

```

#### Rationale for `requiredTier="starter"`:
- The prompt explicitly mandates: *"Register `/dashboard/aura` and `/dashboard/aura/*` wrapped in `<SubscriptionGate requiredTier="starter">`"* and *"Register `/dashboard/phi-scrubber` and `/dashboard/phi-scrubber/*` wrapped in `<SubscriptionGate requiredTier="starter">`"*.
- In `SubscriptionGate.tsx`, any subscriber on `starter`, `pro`, or `group` (or trialing) satisfies `tierWeight[tier] >= tierWeight['starter']` (weight 1 >= 1).
- Unauthenticated users remain strictly blocked by `<ProtectedRoute>` and redirected to `/login` (tested in `T2.1.4` and `T2.1.5`).
- Unsubscribed users are blocked by `<SubscriptionGate>` and prompted to subscribe.

  const sendToPhiScrubber = (text: string) => {
    setScrubberInputText(text);
    if (typeof window !== 'undefined') {
      window.dispatchEvent(
        new CustomEvent('clinical:send-to-phi-scrubber', {
          detail: { text, patient: activePatient },
        })
      );
    }
  };

  const clearScrubberInput = () => {
    setScrubberInputText('');
  };

  const insertToEhr = (note: EhrNoteInput) => {
    // 1. Synchronously update activeEncounterNotes
    if (typeof note === 'string') {
      setActiveEncounterNotes((prev) => ({
        ...prev,
        assessment: prev.assessment ? `${prev.assessment}\n\n${note}` : note,
      }));
    } else {
      setActiveEncounterNotes((prev) => ({
        ...prev,
        subjective: note.subjective ?? (note.format === 'dap' ? note.data ?? prev.subjective : prev.subjective),
        objective: note.objective ?? prev.objective,
        assessment: note.assessment ?? prev.assessment,
        plan: note.plan ?? prev.plan,
      }));
    }

    // 2. Asynchronously populate TheraFlow active note store
    (async () => {
      try {
        const { getNotes, addNote, updateNote } = await import('@/tools/theraflow/data/theraflow-store');
        const notes = await getNotes();
        const existingDraft = notes.find((n) => n.client_id === activePatient.id && !n.is_locked);

        if (typeof note === 'string') {
          if (existingDraft) {
            await updateNote(existingDraft.id, {
              a_text: existingDraft.a_text ? `${existingDraft.a_text}\n\n${note}` : note,
            });
          } else {
            await addNote({
              client_id: activePatient.id,
              client_name: activePatient.name,
              client_mrn: activePatient.mrn,
              date_of_service: new Date().toISOString().split('T')[0],
              session_type: `Psychotherapy (${activePatient.cptCode})`,
              duration_minutes: 60,
              cpt_code: activePatient.cptCode,
              diagnosis_code: 'F41.1',
              d_text: 'Clinical Encounter Note',
              a_text: note,
              p_text: 'Continue active treatment protocol',
              is_locked: false,
            });
          }
        } else {
          const dText = note.data || [note.subjective, note.objective].filter(Boolean).join('\n\n');
          if (existingDraft) {
            await updateNote(existingDraft.id, {
              d_text: dText || existingDraft.d_text,
              a_text: note.assessment || existingDraft.a_text,
              p_text: note.plan || existingDraft.p_text,
            });
          } else {
            await addNote({
              client_id: activePatient.id,
              client_name: activePatient.name,
              client_mrn: activePatient.mrn,
              date_of_service: new Date().toISOString().split('T')[0],
              session_type: `Psychotherapy (${activePatient.cptCode})`,
              duration_minutes: 60,
              cpt_code: activePatient.cptCode,
              diagnosis_code: 'F41.1',
              d_text: dText || 'Clinical documentation',
              a_text: note.assessment || '',
              p_text: note.plan || '',
              is_locked: false,
            });
          }
        }
      } catch (err) {
        // Safe fallback in isolated environments without localStorage
      }
    })();
  };

  return (
    <ClinicalContext.Provider
      value={{
        activePatient,
        setActivePatient,
        activeEncounterNotes,
        updateNoteField,
        sendToPhiScrubber,
        insertToEhr,
        scrubberInputText,
        clearScrubberInput,
      }}
    >
      {children}
    </ClinicalContext.Provider>
  );
};

export const useClinicalContext = (): ClinicalContextType => {
  const context = useContext(ClinicalContext);
  if (!context) {
    throw new Error('useClinicalContext must be used within a ClinicalContextProvider');
  }
  return context;
};
