# TheraFlow OS - Strategic Acquisition Brief

TheraFlow combines behavioral health clinical interfaces with practice workforce, compensation, payroll and financial workflow engines. Buyer value is reusable source, synthetic demo workflows, migrations, tests and documentation. This is a technology asset evaluation; customer traction, market pricing, revenue and independent certification have not been established by this package.

## Acquisition thesis

An acquirer can evaluate a unified clinical-to-financial workflow: appointment, encounter, note, claim formatting, synthetic payment, calculated compensation, sandbox payroll and ledger entries. Implemented UI and calculation engines provide a foundation for integration with a buyer's existing infrastructure.

| Delivered | Boundary |
| --- | --- |
| EHR, Scribe, Aura and PHI scrubber interfaces | Clinical reference/drafting aids evaluated with synthetic data |
| Workforce and compensation rules | Integer cents/basis-point allocation helpers |
| Treasury, payroll and double-entry ledger | Synthetic accounts/batches; no live money movement or tax filing |
| Billing/export formatters | No verified payer acceptance, clearinghouse transport or hospital API exchange |
| Database migrations | 31 public tables plus auth shim;59 policy creation statements yielding 58 active public policies |
| API authorization, tenant controls, HMAC audit | Documented security remediations; no independent certification |

Potential buyers include clinical software, practice management, payroll, revenue-cycle and financial-platform engineering teams. These are buyer categories, not claims about specific companies' plans or intent. Integration opportunities need buyer discovery and validation.

## Evaluation and transaction work

Start with ACQUISITION_READINESS.md, BUYER_HANDOFF.md and THERAFLOW_ACQUISITION_DUE_DILIGENCE.md. Inspect code and exact release CI evidence, test synthetic workflows and estimate deployment/integration effort. Review ownership, licensing, dependencies and any transaction representations through the buyer's diligence process; source code alone does not establish clear IP title or zero operational liability.

Replacement cost, asking price, savings, launch dates and future revenue are negotiation assumptions, not validated asset facts. Live banking, payroll, speech, remote telehealth and clearinghouse work remains outside this acquisition snapshot. Keep the published tag immutable; the next separate development project is a polished synthetic staging demo.
